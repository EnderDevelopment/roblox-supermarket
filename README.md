# RobuxShop

RobuxShop is a Roblox script that creates a supermarket where players can buy items with in-game money. The script includes a currency system, silent steps, faster speed, and noise reduction items, along with a store interface for players to purchase these items.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Create a `ServerScriptService` folder if it doesn't already exist.
4. Place each script in the `ServerScriptService` folder as described below:
   - `CurrencySystem.server.lua`
   - `SilentSteps.server.lua`
   - `FasterSpeed.server.lua`
   - `NoiseReduction.server.lua`
   - `StoreInterface.server.lua`

## Use

1. Start the game in Roblox Studio.
2. Players will automatically receive a starting amount of currency.
3. Players can open the store interface to purchase items:
   - Silent Steps (200 currency)
   - Faster Speed (300 currency)
   - Noise Reduction (250 currency)
4. Purchased items will provide the corresponding effects to the player's character.
